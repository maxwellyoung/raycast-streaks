# Streaks

Raycast extension for tracking habit streaks from the launcher.

Streaks is a small productivity utility for creating habits, checking current progress, and quickly adding completions without opening a full habit-tracking app.

## What it demonstrates

- Raycast extension structure with multiple commands.
- Fast command-palette workflows for repeated personal productivity tasks.
- TypeScript implementation with Raycast lint/build checks.
- A focused utility surface instead of a broad dashboard.

## Commands

- `Manage Streaks`: view and manage existing streaks.
- `Add Streak`: create a new habit streak.
- `Check Streaks`: review current streak progress.
- `Edit Streak`: update an existing streak.
- `Quick Add Streak`: add progress quickly from Raycast.

## Run locally

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```
